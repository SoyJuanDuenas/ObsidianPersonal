
A **classification problem** is a type of [[supervised statistical learning]] task where the goal is to predict a **discrete category or class label** from one or more input variables.

Given a dataset with input variables $X$ and a target variable $y$, classification aims to learn a function:

$$f(X) \approx y$$

where $y$ takes values from a **finite set of classes**, such as:

- spam / not spam
- benign / malignant
- yes / no
- fraud / not fraud
- cat / dog / bird

## Examples

- Predicting whether an email is **spam** or **not spam**.
- Classifying a tumor as **benign** or **malignant**.
- Determining whether a transaction is **fraudulent** or **legitimate**.
- Recognizing whether an image contains a **cat**, **dog**, or **bird**.
